# CS2_OS
All of my study material pertaining towards the Operating Systems Module (Aston University) 

## Motive:

This repository serves to provide the outline for all of my solutions to Lab and Tutorial Contents in the Operating Systems module - acting my all encompassing learning aid.

## Contents:

Each of the following Lab and Tutorial contents will be given their own individual folder. Note that some of the implementation was made pre-emptively before the module began; only going off of the materials that were made available on Blackboard circa. 19th January 2026. Therefore, anything shown may be subject to change and or reflect an outdated understanding of module contents. 

## Buidling:

The following build scheme provides a simple ease of use means of building per contents of each Lab or Tutorial should they require it

Simply run the following from the root of the cloned repository 

``make clean and make LABXX``
